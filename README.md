# Task Management Application

A responsive Task Management Application built using React, Node.js, and Express.js.

## Features

* Create new tasks
* View all tasks
* Update task status
* Delete tasks
* Responsive dashboard interface
* REST API integration

## Technologies Used

**Frontend**

* React
* Vite
* CSS

**Backend**

* Node.js
* Express.js
* REST API

## Project Structure

* `frontend/` — React user interface
* `backend/` — Express.js API server

## How to Run Locally

### 1. Start the Backend

Open a terminal and run:

```bash
cd backend
npm install
node server.js
```

The backend runs at `http://localhost:5000`.

### 2. Start the Frontend

Open another terminal and run:

```bash
cd frontend
npm install
npm run dev
```

Open the local URL shown in your terminal.

## Note

Tasks are stored in memory, so they reset when the backend server restarts.
